Acerca del proyecto

Esta aplicación web fue desarrollada utilizando Python y el framework Flask.

El proyecto tiene como finalidad promover y fomentar una buena alimentación entre los estudiantes, impulsando hábitos saludables y una mejor calidad de vida.

La aplicación permite presentar información relacionada con la buena alimentación de una manera sencilla, organizada y fácil de comprender.
